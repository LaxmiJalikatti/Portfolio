## 📌 About

This portfolio was built using HTML, CSS, and JavaScript to present my technical skills, projects, resume, and contact information in a clean and interactive way.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Smooth scrolling navigation
- Active section highlighting in navbar
- Typing animation in the Home section
- Dark / Light mode toggle with saved preference
- Interactive hover effects on skill and project cards
- Resume download button
- Back to Top floating button
- Project cards linked directly to GitHub repositories
- Contact section with Email, GitHub, and LinkedIn links

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
